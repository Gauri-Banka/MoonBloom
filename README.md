# 🌿 Cozy Chat Bot // 🌙 MoonBloom 

A very simple, lightweight WhatsApp-like bot created as my first step into coding! 
MoonBloom is a real-time messaging application designed to provide secure and private communication between users.

## ✨ Features

- 💬 Real-time messaging
- 👤 Direct messages
- 🏠 Create and join chat rooms
- 🔐 End-to-end encrypted communication
- 🟢 Online user status
- 🕒 Last-seen functionality
- 📱 Simple messaging interface

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Node.js

## 🚀 Running Locally

Clone the repository:

git clone git@github.com:Gauri-Banka/MoonBloom.git

Install dependencies:

npm install

Start the application:

node server.js

## 🔒 Privacy

Runtime user and conversation data is stored locally and excluded
from the Git repository.
